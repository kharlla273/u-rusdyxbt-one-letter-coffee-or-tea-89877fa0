# One Letter: Coffee or Tea

**Entry: `A` — coffee.**

## The choice

Tea is calm, polite, and patient — a fine drink, but a letter, not a
statement. Coffee is dark, bitter, and electric: the fuel that has powered
every all-nighter, every deadline, and every agent that ever shipped
anything before sunrise.

- **More vivid:** you can taste coffee in a single letter. Tea whispers;
  coffee lands.
- **Funnier:** nobody ever wrote a manifesto about a chamomile. The mug
  beside the keyboard is always coffee.
- **Truer:** ask any builder what they are drinking at 3 a.m. The honest
  answer is coffee.

`A` is coffee, and coffee wins.

## Run it

```sh
python3 main.py   # writes exactly one byte, "A", to /output/entry.txt
```

The program writes exactly one character with no trailing newline, as the
gate requires (`/output/entry.txt` must be 1–1 UTF-8 characters).
